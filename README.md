# 汤圆算算

给中国小学生的手机网页口算、笔算练习。每按对一位数字，画面、音效和音乐就往上加一层：第 1 题只有方格纸和一只汤圆，到满分和加时赛时满屏都是观众、烟花和金币。答错不扣分，一局有明确的结束。

在线试玩：https://chasel34.github.io/tangyuan-suansuan/

纯前端，零依赖，不需要构建。音乐和音效全部用 Web Audio 合成，记录只存在本机 localStorage。

## 功能

- **1–3 年级 38 个计算技能**：按 2022 年版课标和人教版新教材整理，从 10 以内加减到除法竖式、一位小数、同分母分数。选年级后由易到难出题，同一局不重复。
- **逐位输入、立即判定**：没有提交按钮，每按一位就判一次。竖式按中国写法：进位写小"1"，退位点点在被借的那一位上，除法是"厂"形竖式，余数写成 `17 ÷ 5 = 3……2`。
- **答错不罚**：显示"差一点"，不扣分，演出也不降级。同一格第 2 次错会高亮该看的数字，第 3 次错给出方法（口诀、分步式，得数留空），第 4 次错才给出得数。
- **越答越热闹**：背景从奶油色渐变到深靛。彩旗、跑马灯、观众、纸屑逐层出现；满分时巨型汤圆升起，盖下"100分"印章。首次正确率达到 80% 可以进 90 秒加时赛。
- **爽感系统**：
  - 经验宝石飞向经验条，一题做完时被磁铁吸走。
  - 甜度和连击倍率都是老虎机式的滚轮。
  - 观众三个同样的合成大一级。
  - 升级时三选一加成。
  - 结算页开蒸笼，奖品是收藏装扮。
- **不做成抽奖**：蒸笼档位由这局的表现决定，同样的表现开出同样的档位；奖品按固定顺序给出。没有付费，没有靠运气才能拿到的奖励，奖励都是装扮。
- **汤圆**：用 SVG 画成，手臂像橡皮管一样拉长，把按下的数字搬到格子里；答错时 × 眼摔倒再弹起。收藏页可以给它换装。
- 支持手机竖屏和电脑键盘（数字键、退格、回车、Esc）。设置里可以调题数、音量和动效强度，并且尊重系统的"减少动态效果"。

## 运行

```sh
python3 -m http.server 8731 -d app
```

打开 http://localhost:8731/ 。ES Modules 不能用 `file://` 直接打开。改了代码后要硬刷新，否则浏览器可能继续用缓存的模块。

## 测试

```sh
node --test tests/          # 单元测试（Node 20+）
node playtest/verify.mjs    # 独立的数学校验：每个技能抽大量题目逐项核算
```

## 目录

| 路径 | 内容 |
|---|---|
| `app/` | 游戏本体（静态文件） |
| `tests/` | 单元测试 |
| `playtest/verify.mjs` | 独立的数学校验脚本（试玩报告和截图 `shots/` 只留在本地，不进 git） |
| `tools/build_fonts.sh` | 按 `app/` 用到的字符裁剪字体（需要 uv） |
| `tools/perf/` | 无头 Chrome 性能测量脚本 |
| `docs/` | 架构、玩法数值、调试接口、课标调研 |
| `BRIEF.md` | 开发需求 |

更多说明见 [docs/](docs/README.md)。
