# 中国版设计笔记：数学 / 语文 / 英语

调研原文：`research/shuxue.md`、`research/yuwen.md`、`research/yingyu.md`。

## 1. 三科共用的引擎

原版的核心只有一个循环：题目预先算好"答案格序列"，玩家每按一个数字键，就和序列里的下一格比较，对了就往前走一步，演出加一层。要让语文和英语也能用，把它抽象成两件事：

- **token 序列**：每道题存一组合法答案（不止一个），每个答案是一串 token。token 可以是一位数字、一个汉字、一个声母、一个笔画名、一个字母、一个字母组合（`ee`、`a_e`）、一个单词。每按一次键，检查"已输入内容 + 这一键"是否还是某个合法答案的前缀，是就判对。这样 colour/color、多种语序、带分数和假分数都能同时接受。
- **动态键盘**：键盘的按键由题目决定，不再固定是 0–9。数学是数字键，语文是 6–8 个候选字块或拼音键，英语是目标字母加 3–5 个易混字母。

其他部分三科通用：演出强度 `E` 按"已完成步数 / 总步数"计算（原版按题数），答错不扣分、三级提示、技能树、掌握度（只有第一次就按对才计入）、さび、タイムカプセル、奖杯、收藏。

原版代码是 MIT，可以直接改；但吉祥物「ドパキチ」和「ドパドリル」名称、logo 不在 MIT 范围内，商用需要授权，所以中国版必须换新吉祥物和新名字。

## 2. 数学：基本照搬，改 8 处

72 个技能（主线 70 + 可选 2），前提关系按 2022 课标，年级位置按人教新版，详见 `research/shuxue.md`。和原版相比要改的地方：

1. 乘法口诀按中国"小九九"45 句的顺序：5 → 2、3、4 → 6 → 7、8、9，每句交换顺序出题。
2. 余数写成 `17÷5=3……2`。
3. 竖式退位用"退位点"，不是划掉数字重写。
4. 新增**脱式计算**：混合运算一步一行、每行以"="开头，逐步输入中间结果。
5. 新增 □ 填空（`□+7=15`）、"≈"估算（题面写明取整规则）、比 `a:b`、"%"后缀、1–4 选择题。
6. 小数点移动、分数化小数这类题，小数点位置本身就是考点，不能像原版那样自动放好，要加一个"."键。
7. 小数除法只出能除尽的题（新教材已删去循环小数和商的近似数）。
8. 解方程、解比例已按 2022 课标移到初中，只作可选技能。

## 3. 语文

### 3.1 什么内容适合
语文不像数学能无限生成，内容来自有限的字表、词表、诗文库，所以题目重复是常态。原版的 さび（21 天没练就生锈）和 タイムカプセル 在这里比在数学里更有用，相当于间隔复习。

优先做的技能（全部能用开源数据加少量人工校对完成）：

| 技能 | 一题的步数 | 键盘 |
|---|---|---|
| 古诗逐字补全 | 一句 5 或 7 步，节奏最接近原版的竖式 | 6–9 个字块，干扰字用同音字、形近字 |
| 看拼音写词语 | 2–4 步 | 6–8 个字块 |
| 拼音拼读 | 声母 → 韵母 → 声调，2–4 步 | 拼音键盘（三排：声母 / 韵母 / 声调） |
| 笔顺 | 一个字 n 笔就是 n 步 | 6–8 个笔画名按钮（带笔形图标） |
| 成语补字 / 按序点字 | 1 步或 4 步 | 字块 |
| 同音字、形近字辨析 | 1 步 | 2–4 选 1 |
| 多音字据义定音 | 1 步 | 2–3 个读音 |

不做：作文、阅读理解、朗读、背诵本身、修辞和句子成分（课标规定"语文知识的概念不作考试内容"）。

### 3.2 界面
- 题卡用**田字格**代替方格纸，诗句空位是虚线田字格。
- 吉祥物用长手臂把字块从键盘搬到田字格，和原版搬数字一样。
- 字体用霞鹜文楷 GB（SIL OFL，可商用，字形符合大陆规范）。

### 3.3 难点
- **唯一答案**：组词、近反义词、量词天然有多解，出题时必须用词典反查，保证干扰项填进去不成词。
- **拼音录音**：单音节带声调的 TTS 不稳定，要真人录。
- **教材字表**：各册识字表、写字表没有可靠的开源版，要人工录入；约 2500 字的笔画名序列要按 GF 0023-2020 逐字核对。这是工作量最大的部分。
- **手写**：Hanzi Writer 能逐笔判定手写，但手写比点按钮慢得多，会打断节奏。建议笔顺主模式用点笔画名，手写单独做一个慢节奏模式。

## 4. 英语

### 4.1 什么内容适合
课标小学只要求约 505 词，音标是初中内容，小学不显示音标。优先做：

| 技能 | 一题的步数 | 键盘 |
|---|---|---|
| 主题词汇（16 个主题，每个分三档：听音点图 → 看图点词 → 看图拼写） | 1 步或 n 个字母 | 图片 / 候选词 / 字母键 |
| 自然拼读（按 PEP 顺序：短元音 → a-e 等 → ch/sh → ar/or → ai/ee 等 → 辅音连缀） | 只挖目标位置，1–2 步 | 组合块键（`sh`、`ee`、`a_e`） |
| 词尾变形（复数、三单、-ing、-ed、比较级） | 1–3 步 | 字母键，只补词尾 |
| 连词成句（只出语序唯一的句型） | 4–7 步 | 单词块 |

不做：口语评测、长篇阅读、写作、句型转换。

### 4.2 界面
- 题卡用**四线三格**代替方格纸。
- 键盘只放目标字母加易混字母（b/d/p/q、e/i、c/k/ck），手机竖屏放 26 键太挤。
- 课标词表是英式拼写，判定时同时接受美式。

### 4.3 难点：音频
- **不要依赖浏览器 TTS（Web Speech API）**：微信安卓内置浏览器很可能不支持，TTS 也念不出 /k/、/æ/ 这样的单音。
- 单词和句子用离线预生成的**英式**音频（教材录音是英音，美音在 o、ar、or 上和教材不同）。
- 约 60 段单音由真人录制。
- 1000 词加 500 句约 9MB，按技能分包加载。
- iOS 静音开关、微信内的自动播放都要实机测试。

## 5. 建议的顺序
1. 先做**数学**：原版代码几乎能直接用，主要是换皮和改上面 8 处。
2. 引擎改成"token 序列 + 动态键盘"，用**语文古诗补全**验证：它不需要音频，数据来自开源诗文库，一句 5–7 步，节奏和竖式最像。
3. 最后做**英语**，因为要先解决音频制作和微信播放。
