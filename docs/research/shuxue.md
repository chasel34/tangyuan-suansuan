# 中国小学计算技能树调研（按2022课标和人教版新教材整理）

## 0. 先说结论和几点注意

- **课标原文已核对。** 我下载了教育部官网的《义务教育数学课程标准（2022年版）》PDF（扫描版，已 OCR），逐页读了"数与代数"三个学段的内容要求、学业要求，以及学业质量部分。
- **计算相关的硬性要求很少，原文如下：**
  - 第一学段：「能熟练口算20以内数的加减法和表内乘除法，能口算简单的百以内数的加减法；能计算两位数和三位数的加减法」。
  - 第二学段：「能计算两位数乘除三位数」；「会进行同分母分数的加减运算和一位小数的加减运算」；「整数四则混合运算（以两步为主，不超过三步），正确运用小括号和中括号」；「能运用运算律进行简便运算」。
  - 第三学段：「能进行简单小数和分数的四则运算和混合运算（不超过三步）」；「会进行小数和分数的转化（不包括将循环小数转化成分数）」；「在1～100的自然数中……10以内两个自然数的公倍数和最小公倍数」；「能在具体情境中判断两个量的比，会计算比值……按比例分配」；「了解负数」。
- **2022课标和旧教材有三处大的不同：**
  - 负数的运算、方程（包括解一元一次方程）移到了初中第四学段，小学只保留"等式的基本性质"和"用字母表示"。
  - 百分数移到了"统计与概率"领域。
  - 小学只保留"成正比的量"，没有反比例。
- **口算速度：2022课标里没有任何按分钟计的量化要求。** 网上常见"一年级每分钟8～10题"之类的说法，都来自无出处的网页，据说出自旧大纲（1992/2000年版），但我没找到原文核实。建议游戏自己定熟练标准，不要写成"课标要求"。
- **人教版正处在新旧教材交替期（截至2026年秋）：**
  - 新版：一上（2024）、一下（2025）、二上（2025）、二下（2026）、三上（2025）、三下（2026）、四上/五上/六上（2026秋）。
  - 现行仍为旧版：四下、五下、六下。
  - 下表"教材"列会标出按哪一版排的位置。课标和教材冲突时以课标为准，旧教材独有的内容标成【可选】。

**有四处我没能确认，请注意：**
1. **两位数除法的位置。** 新版四上目录里已经没有"除数是两位数的除法"。"移到四下"只有一篇二手文章（aoshu.world）这么说，新版四下还没出版。
2. **"比"的位置。** 新版六上目录里没有"比"单元（旧版六上第4单元是"比"）。课标要求第三学段学比，新版具体放在哪一册还不确定。北师大、苏教的新版都在六上。
3. **口算速度。** 见上文，无法核实。
4. **解方程、解比例。** 旧版五上"简易方程"、六下"解比例"目前还有学生在用；新版五上已删去解方程（有新闻报道，目录也改名为"用字母表示数和数量关系"）。表中只作为【可选】技能。

## 1. 计算技能表（72个：主线70个，另有2个【可选】）

表中用了下面这些约定：

- **系统**分四列，对应原版的4条 lane：加减 / 乘除 / 小数分数 / 其他。
- **前提**列只引用本表内的 id，已检查过是闭合的。
- **生成器**尽量对应原版 `problems.js` 已有的类型：hadd/hsub（横式）、vadd/vsub（竖式加减）、vmul（竖式乘）、vdiv（除法竖式）、divRem、frac、vdec、order、round、letter、ratio、percent、gcdlcm、compose。标★的需要新写生成器。
- **输入形式**的写法：
  - 「横式」：一位一位输入答案。
  - 「竖式」：按书写顺序逐位填。
  - 「分数」：先分母后分子，与原版一致，也和中国"先写分数线，再写分母，再写分子"的教法相同。
  - 「商……余」：商和余数两组格子，中国的写法是 `17÷5=3……2`。
  - 「□」：在算式中间填空。

### 需要新写或扩展的生成器（原版没有现成的）
1. **□填空（g1a-missing、g2b-missing）**：答案格子在算式中间。
2. **脱式计算（g3a-mix2、g4b-mix3、g6a-fmix）**：每步一行，每行开头"="，逐步输入中间结果。这是中国特有的书写格式，建议作为这几个技能的默认输入。
3. **估算"≈"（g3a-est）**：必须把取整规则显示在题面上。
4. **比 a:b 两格（g6a-ratio）**。
5. **"%"后缀（g6a-pct、g6a-pctof）**。
6. **选择题（g5b-factor）**：用数字键1～4选。
7. **小数点由学生输入（g4b-shift、g5b-f2d）**：见第3节。
8. **小数除法"添0继续除"（g5a-ddi、g5a-ddd）**：扩展 vdiv，被除数末尾可以补0继续除，商里的小数点对齐被除数的小数点。

## 2. 与日本版的主要差异

**口诀和口算**
1. **乘法口诀的结构不同。** 中国"小九九"只有45句，每句只写小数在前的那一种（"三七二十一"同时管3×7和7×3），所以"2的口诀"只有 1×2、2×2 两句。学习顺序是 5 → 2、3、4 → 6 → 7、8、9。日本九九按段背81句。生成器应改成 a∈[1,n]×n，并且交换顺序出题。
2. **口算技能比日本多。** 两位数加减两位数口算、整十整百数的乘除口算、除数是整十数的口算除法都各是一个教学单元。日本同类内容多直接用筆算做。

**除法**
3. **除法学得早。** 中国的表内除法在2上，紧跟表内乘法；有余数的除法和它的竖式在2下；除数是一位数的除法在3下；除数是两位数的除法在4年级。日本わり算在3年，筆算在4年。
4. **余数的写法。** 中国写成 `17÷5=3……2`（六个点），不写"あまり"。
5. **除法竖式版式和日本基本一样**（"厂"形，商写在对应数位上方，商中间有0时可以省略一行乘积），原版的 vdiv 布局可以直接用。区别在教法：中国教"四舍五入法试商"和"调商"，提示文字可以用这些说法。
6. **小数除法的答案形式不同。** 中国要求"添0继续除，除到没有余数"，新版还删去了商的近似数和循环小数。日本有"あまりのある小数のわり算"和"概数で商を求める"。不要照搬日本的出题方式。

**竖式标记和书写格式**
7. **进位、退位的标记不同。** 中国进位写一个小"1"；退位是在被借的那一位数字上方点一个"退位点·"。日本常见的是把数字划掉再改写。进位、借位自动显示时应改成中国样式。
8. **脱式计算（递等式）是中国特有的书写要求。** 混合运算要求一步写一行，每行开头写"="。日本通常只写最终结果。

**混合运算和运算律**
9. **混合运算更早，并有中括号。** 新人教把两步混合运算放在3上（旧版在2下），三步混合和中括号在4下。日本"計算のきまり"在4年。
10. **运算律和简便计算分量重得多。** 四下有整个"运算律"单元，常见题型是 25×4、125×8 配对，99×a+a，102×45，凑整和"多加少减"。日本版只有一个 g4-order，中国版拆成了 lawadd 和 lawmul 两个。

**小数和分数**
11. **小数乘除集中在一个学期。** 人教在五上一次学完小数乘整数、乘小数、除以整数、除以小数。日本分成4年（×÷整数）和5年（×÷小数）两段。苏教新版更晚，放在五上和六上。
12. **分数乘整数更晚。** 中国同分母加减在3上，异分母在5下，分数乘整数、乘分数和分数除法都在6上。日本分数×÷整数在5年。
13. **带分数的地位不同。** 中国没有"带分数加减"这样的专门技能，答案只强调"化成最简分数"；是否必须化成带分数各地要求不一，建议最简假分数和带分数都判对。日本版的 g4-frac-mixed 在中国没有对应单元。

**百分数、比、方程、负数**
14. **百分数在六年级，并有中国特有的说法。** 课标把百分数放进"统计与概率"。计算上有"几折""几成"、税率、利率等，这些日本没有。日本"百分率"在5年。
15. **比和比例更多。** 两国都在6年级学比。中国旧版六下另有"解比例"和"按比例分配"。
16. **方程已退出小学。** 旧人教五上有整个单元的"解简易方程"（ax±b=c）。2022课标和新人教把它移到了初中，只保留代入求值和"等式的基本性质"。比日本的"xをもとめる"更少，所以放成【可选】。
17. **负数只认识不计算。** 课标第三学段只要求"了解负数"，运算在初中。新人教只在六上有一个☆活动，旧版在六下。两国小学都没有负数运算，不设技能。
18. **因数倍数多了质数和合数。** 中国五下（北师大在五上）有2、3、5倍数特征和质数、合数，日本的素数在中1。

**估算和大数**
19. **估算更早，而且答案不唯一。** 中国从二、三年级就用"≈"估算。教学上允许多个合理答案，所以游戏必须把取整规则写在题面上。日本概数在4年。
20. **大数的分级相同。** 两国都按四位一级用万、亿，"改写成以万为单位"这类题可以复用 round 生成器。

**与北师大、苏教版的顺序差异**
21. **北师大：** 运算律在四上，倍数与因数在五上，分数乘法在五下，六上第一单元就是分数除法，比在六上。
22. **苏教：** 两位数乘除以一位数在2下，两位数乘两位数在3下，两、三位数除以两位数在4上，小数乘除分到五上和六上，比和比例在六上。
23. **结论：** 技能树的前提关系在三个版本里通用，只是"年级学期"一列要按版本调整。建议把"年级"做成显示标签，不作为解锁条件。

## 3. 不适合"数字键盘逐位输入"的内容及处理建议

| 内容 | 建议 |
|---|---|
| 应用题、"数量关系"单元（一下"数量间的加减关系"、二下"数量间的乘除关系"、新四上"加法模型和乘法模型"、路程=速度×时间、总价=单价×数量、按比分配、鸡兔同笼、植树问题） | 排除。最多改成固定句式的一行题，例如「单价12元，买5个，共□元」，不做真正的阅读理解题 |
| 图形与几何（周长、面积、体积、角、圆、观察物体、图形运动） | 排除。面积、周长公式代入可以并入 g5a-letter 的题面，例如「长方形长8宽5，面积=□」 |
| 统计与概率（统计表、条形/折线/扇形统计图、平均数、可能性） | 排除。"求平均数"可以作为可选的横式题 |
| 时、分、秒，年月日，人民币，长度和质量单位 | 不单独设技能。单位换算（如 3.05米=□厘米）可以作为 g4b-shift 的变体 |
| 比较大小（>、<、=）、判断奇偶、判断质数 | 做成选择题：数字键1～3对应 >、<、=，或者用1～4四选一 |
| 估算 | 保留，但题面必须写明取整规则，否则答案不唯一 |
| 近似数、商的近似数、循环小数 | 整数近似数保留（g4a-approx）。新版小学已删去循环小数，商的近似数不做 |
| 小数点位置本身就是考点的题（小数点移动、分数化小数、小数乘法积的小数位数） | 原版的做法是小数点自动放好，这会直接泄露答案。建议加一个"."键，或者给出足够多的空格，让学生自己选小数点位置 |
| 用字母表示数量关系（写式子 a+3、3a） | 键盘无法输入字母，只做"代入求值"。"化简 5x+3x=□x"可以作为系数填空 |
| 解方程、解比例 | 已设为【可选】（g5a-eq、g6b-prop），用横式 x=□ 输入 |
| 负数 | 不设技能（小学不学运算）。如果想要，可以做"温度从3℃降到−2℃，下降了□℃"这类固定题，但超出了课标的运算要求 |
| "说出算理""用两种方法计算"等过程性要求 | 无法评估。脱式逐步输入可以部分体现 |
