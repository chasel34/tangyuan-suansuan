## 0. 已核实的课标与教材要点

**《义务教育语文课程标准（2022年版）》**：从教育部官网下载了原版 PDF（扫描件），逐页 OCR 后核对了原文。

|---|---|---|---|---|
| 第一学段（1–2年级） | 认识约1600字，会写约800字 | 读准声母、韵母、声调、整体认读音节；能准确拼读；认识大写字母，熟记字母表。掌握基本笔画和常用偏旁部首，按基本笔顺规则写字。学会音序检字法、部首检字法 | 体会句号、问号、感叹号的语气；学习使用逗号、句号、问号、感叹号 | 积累成语、格言警句；背诵优秀诗文50篇（段） |

"语言文字积累与梳理"任务群的教学提示里还有几条对设计有直接影响的规定：
- 一年级两个学期会认的字大致为250个和350个，其中一半会写。
- 先认、先写附录4《识字、写字教学基本字表》中的字。
- "语文知识的概念不作考试内容"。

附录一共五个：
- 附录1：优秀诗文背诵推荐篇目共135篇（段），其中1–6年级75篇，全部是诗歌，从《江南》到《村居》。
- 附录3：列出12种常用标点和8种修辞手法，并说明要避免围绕概念做机械操练。
- 附录4：基本字表300字，附13个部首变体。
- 附录5：常用字表3500字，分为字表一2500字、字表二1000字。

**统编教材（2024年起修订版）**。出处是徐轶（人教社小学语文编辑室主任）2024年的文章，已读全文：
- **识字量调整**：一上识字从300字减到280字，写字100字，其中绝大多数来自基本字表；一下和二上各增加10个识字。
- **笔画和笔顺**：一上附表改为完整收录32个楷体笔画的《笔画名称表》。笔顺规则两两成组教：先横后竖、先撇后捺，然后先上后下、先左后右，然后先外后内、先中间后两边。
- **偏旁改名**：宝盖→宝盖头，走之→走之底，禾木旁→禾字旁，穴宝盖→穴字头。
- **检字法**：一下学音序检字法，二上学部首检字法。
- **二年级字形辨析**：梳理多音字（"据义定音"）；部件易错字（纸、低）、结构易错字（荡、满）；形近偏旁辨析（两点水/三点水，示字旁/衣字旁）；"识字加油站"从"幕、慕、墓"中选字填词。
- **二下"书写提示"**：讲形旁变体，"又、土"作偏旁时捺变点、横变提，"车、牛"作偏旁时笔顺改变。
- **"识字加油站"**：一至五年级都有，形式包括事物归类、反义词识字、场所与职业、家庭称谓等。

**语文园地栏目**（二手资料）：
- 低年级：识字加油站、字词句运用、书写提示、日积月累、我的发现、展示台。
- 中年级：交流平台、词句段运用、日积月累，穿插识字加油站和书写提示。
- 高年级：交流平台、词句段运用、日积月累，书写提示不固定。

"日积月累"的类型有：古诗、按主题分组的成语（春天、动物、数字、典故等）、谚语、歇后语、名言警句、对韵、二十四节气歌、数九歌、十二生肖、文化常识。

**未核实的数据**：

## 1. 技能清单（59个）

**图例**
- 年级：1上表示一年级上册。
- 来源：**规则**表示按规则生成，不需要外部数据；**开源+规则**表示用开源数据按规则生成；**人工**表示需要人工编写题库。
- "唯一性"一列说明怎样保证每一步只有一个正确答案。这是"按一下就判"能否成立的前提。组词、近反义词、量词、同音字这类题天然有多个正确答案，必须靠这一列的做法压到只剩一个。

**技能树结构**。依赖关系无环，前提技能的年级都不晚于后续技能。主干有四条：
- P1→P3→S1：拼音到识字。
- B1→B3→B5：笔画到逐笔笔顺。
- R1→R5→F2→F4：偏旁到形近字到改错字。
- S1→G1：识字到古诗。

每个"按册"的技能（S1、S2、B5、W1、W2、G1）的题目池，按"当前册及以前的识字表或写字表"切片，所以同一个技能可以随年级逐步扩大题目池，不需要为每一册单独建技能。

## 2. 输入形式：怎样做到按一下立即判，怎样给分级提示

通用原则：每个题目在出题时就预先算好"期望的下一步"序列，每次按键只和序列中的下一项比较，不设提交按钮。答错不扣分，也不跳过这一步；提示逐级增强，直到孩子自己按对为止。

| 输入形式 | 立即判的机制 | 分级提示（第1次错 → 第2次错 → 第3次错） |
|---|---|---|
| **N选1候选按钮**（4–6个） | 按一下就和答案比较。出题时用字典反查干扰项，确保没有干扰项也碰巧正确 | 把按错的按钮灰掉并提示类别（"和水有关""它读第三声"）→ 再灰掉一半候选，或显示拼音、首笔 → 高亮正确按钮，要求孩子点它 |
| **拼音键盘**（声母键、韵母键、声调键） | 状态机逐键比较。<br>零声母：安 ān 的第一步期望是韵母键，这时按任何声母键都判错。<br>y、w：按教材算作声母；16个整体认读音节做成整键，直接点。<br>ü：j q x y 之后期望的是 u 键，按 ü 键判错，同时触发 P7 的规则提示。<br>声调：最后按声调键，标调位置由程序自动渲染 | 高亮正确键所在的区域（声母区或韵母区）→ 播放本音节录音 → 高亮正确键 |
| **顺序点字块**（古诗、成语、看拼音写词语、连词成句） | 用"当前位置期望的字符"比较，而不是字块 ID，重复字（鹅鹅鹅）因此不会误判。有多个正确顺序的题，维护一组可接受的顺序，前缀命中就判对 | 在空格里显示该字的拼音 → 显示首笔或该字的轮廓 → 高亮正确字块 |
| **笔画名按钮逐笔点**（B5） | 第 k 步只和第 k 笔的名称比较。按钮每次放6–8个，包括正确项和易混项（横折、横折钩、横撇、横钩），同时显示笔形图标，照顾还不识字的一年级 | 在字上闪烁第 k 笔的位置 → 播放这一笔的书写动画 → 高亮正确名称 |
| **手写描红**（Hanzi Writer quiz） | 库本身逐笔判定，有 `onCorrectStroke` / `onMistake` 回调 | 对应现成参数：`showHintAfterMisses`（错若干次后显示这一笔的提示），`markStrokeCorrectAfterMisses`（错若干次后代写这一笔）。`leniency` 可调判定宽松度，低年级可以放宽 |
| **二选一/三选一**（多音字、褒贬、句末标点、ü 规则） | 同 N选1 | 因为选项少，第1次错就给出规则提示（"'长大'是长高的意思，读 zhǎng"）；第2次错高亮正确项 |
| **连续多选**（分类、主题成语） | 每点一个就判一个，界面显示"还剩 n 个" | 点错的项抖动并变灰；超时或连错后，逐个点亮漏掉的正确项 |
| **多步定位**（改错字、部首检字） | 每一步是一次独立判定：先点错字或部首 → 再点候选或笔画数 → 最后点结果 | 各步分别按上面的规则给提示；例如第一步错时，把句子缩小到含错字的半句 |

**掌握度的记法**：
- 只有第一次就按对的步骤，才计入掌握度。
- 靠提示完成的步骤记为"辅助"，这些题目在后面的局里优先重出。
- 一局6/10/14题，可以按"步数"而不是"题数"来叠加演出层数，对应关系：古诗一句是5或7步，一个音节是2–4步，一个字的笔顺是 n 笔。

**实现前需要准备的资源**：
- **录音**：拼音类技能需要逐个音节、逐个声调的录音。单音节的 TTS 声调不稳定，建议真人录音。
- **字体**：显示用楷体，而且字形要符合大陆规范。可选霞鹜文楷 GB 版，许可证是 SIL OFL 1.1。

## 3. 不适合做成这种形式的课标内容

| 内容 | 不适合的原因 |
|---|---|
| 写话、习作（每学年16次左右）、读书笔记、应用文 | 答案开放，没有唯一的"下一步" |
| 朗读、口语交际、说普通话 | 需要语音评测，没法靠按键判对错 |
| 背诵本身 | 按键只能考"认出和补全"，不能代替出声背诵。G1–G3 是辅助练习，不等于背诵达标 |
| 阅读长文，把握主要内容、体会情感 | 答案开放，需要长时间阅读，和快节奏的逐步判定冲突 |
| 整本书阅读、课外阅读量、默读速度 | 这些是阅读量或速度指标，不是对错判断 |
| 梳理与探究中的调查、研究报告、活动策划、跨媒介阅读、跨学科学习 | 是项目式活动 |
| 毛笔书写、"书写美观"、间架结构的好坏 | 属于审美评价，不是二元对错；按键和描红只能判笔顺和笔画是否正确 |
| 修辞手法识别、词类和句子成分 | 课标规定"语文知识的概念不作考试内容"，附录3也要求避免围绕概念操练；而且判断有争议（比喻和拟人常常同时成立） |
| 仿写、扩句、缩句，"联系上下文推想词义" | 答案不唯一 |
| 古诗的意境和情感体会 | 答案开放；只能退一步做 G4 这类事实题 |
